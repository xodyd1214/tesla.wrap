    차량에 랩 적용하기

    1. 실제 차량과 같은 모델을 고르고, 전개도나 목록에서 파츠를 선택하세요.
    2. 전개도 기준에서는 이미지의 비율을 유지하며 전개도 위에서 끌어 배치합니다. 차량 기준에서는 3D 프리뷰를 돌려 원하는 각도에서 이미지를 배치합니다. 이미지가 선택된 상태에서도 기준을 바꿀 수 있어요.
    3. PNG 내보내기를 누른 뒤 Tesla 앱의 Creations → Wrap → Upload에서 파일을 선택하세요. USB로 옮길 때는 Wraps 폴더에 넣으세요.
    4. 차량에서 Toybox → Paint Shop → Wraps를 열어 적용하세요.

    Model 3 Highland의 3D 프리뷰는 별도 차량 모델을 사용한 근사 시각화입니다. 내보낸 PNG는 Tesla 공식 전개도에 맞춰 저장됩니다.
